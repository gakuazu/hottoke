# 4本目アプリ案: 自由発想によるボールドアイデア

作成日: 2026-10-24
担当: product-researcher
方向性: オーナー指定「おまかせ（自由発想）」

## 進め方（守った約束）

1. 競合・実装・収益を横に置き、感触（触る・吹く・傾ける・揺らす）と感情起点で自由発想（30案）
2. 選別（一人で完結／無料アカウントで動く／既存3本と非重複／最初の30秒の気持ちよさが想像できる）
3. 残した案だけ軽く競合確認（WebSearch）
4. 最終候補には「最初の30秒」と「数日で作れる感触確認用プロトタイプ」を付けた（かおゲーの教訓）

既存アプリと被らないよう除外した方向: 点描リング／日記（1本目）、顔の表情（2本目）、傾けて玉を転がし砂紋を描く（3本目ひとり砂の庭）、万華鏡の対称模様、過去案（docs/01c, 06, 16）の既出テーマ。

## (c) 最終候補（4案）

### 候補A: くもり窓（Fogged Window）

**どんな体験か**
画面に向かって「ふーっ」と息を吹くと、マイクが息を検知して画面が白く曇る。指でなぞると曇りが拭われ、その下に景色（背面カメラのライブ映像、または写真・イラスト）が見える。拭いた部分は時間とともにじわっと再び曇り、なぞった縁から水滴ができて筋になって垂れる。スマホを傾けると水滴が傾いた方へ流れる。拭いた景色は写真として保存できる。

**最初の30秒の気持ちよさ**
- 起動すると真っ白に曇った画面。「ふーっ」と吹いた瞬間に白がぶわっと濃くなる（息に反応する驚き）
- 指で一撫でして曇りの下からぼんやり景色が現れる（ガラスを拭く感触）
- 縁に水滴がぷくっと膨らみ、つーっと垂れる
- 触覚は拭くときのキュッキュッという細かい振動

**なぜ一人で続けたくなるか**
- 息→曇る→拭く→また曇る、というサイクルに終わりがなく、手持ち無沙汰の時間に触りたくなる
- 窓の外が日替わりで変わる（カメラは今いる場所。目の前の景色が曇りガラス越しになる＝毎回違う絵になる）
- 指で字や絵を描いて眺める遊び方も自然に出る。作品を撮って残せる

**最小プロトタイプ案（目安2〜3日）**
- SwiftUI Canvasで全面に白いレイヤーを貼り、指の軌跡を消しゴム（マスク）として描く。時間経過で軌跡を少しずつ薄く戻す
- 息検知は `AVAudioEngine` で音量(RMS)と低音域の割合を見る簡易判定。まず「画面を長押ししている間も曇る」代替入力を付けて、息検知が不安定でも感触を試せるようにする
- 水滴は拭いた縁にランダム生成し、下方向へ移動する小さな円（重力は CoreMotion）
- 背景はまず固定の写真。カメラ映像は後回し
- 判定基準: 実機で30秒触って「また撫でたい」と感じるか

**実装の難しさ**: 低〜中。マイクとカメラの許可のみ。AVAudioEngine・Canvas/Metal・CoreMotionで完結（有料機能・サーバー不要）。リスクは息検知の誤作動（周囲の騒音）と、曇りの質感の描画品質（ぼかし・屈折）。後者は画像ぼかしを重ねる程度でも成立する。

**軽い競合確認の結果**
- 2009年に「iSteam」「iFog」が同じ発想で大ヒット（iSteamは初月200万DL）。ただし現在のApp Storeでは確認できず、古くて現行iOSでは使えない可能性が高い
- 現行で同じ息→曇り→拭くを高品質にやっている iOS アプリは今回の検索で見つからなかった（ただし検索は1回で網羅的ではない）
- 「過去に大衆に受けた」という実績と、現行品が見当たらない空白が両立している

**収益化の想像**: 無料で基本の曇りと数種の景色、買い切りで景色パック（雨の車窓・浴室の鏡・冬の窓など）、写真保存の高画質、水滴スタイル。広告との相性は悪い（没入体験）。

### 候補B: 窓の雨粒ころがし（Raindrop Run）

**どんな体験か**
雨に濡れた窓ガラスを見ているような画面に、大小の水滴が付いている。スマホを傾けると水滴がつーっと走り、他の水滴に当たると合体して大きくなり、重くなって勢いよく流れる。指でつつくと水滴が弾けて小さな粒に分かれる。

**最初の30秒の気持ちよさ**
- 傾きに合わせて水滴が流れる「重さ」が伝わる
- 2つの水滴がぷるんと合体する瞬間の視覚と、軽いタップ触覚
- 背景の景色（街の夜景ボケ）が屈折で水滴の中に逆さまに映る

**なぜ一人で続けたくなるか**
- 水滴の動きは毎回違う。ぼんやり眺めて、たまに傾けるだけで気持ちが落ち着く
- 大きな水滴を作る「集めたくなる」小さな目的が自然に生まれる

**最小プロトタイプ案（2〜3日）**
- 円（水滴）を数十個生成し、CoreMotionの重力方向に加速。接触したら質量を足して合体
- 屈折の表現はまず省き、半透明の円に影をつけただけの2D表示
- 判定基準: 傾けて合体させるだけで気持ちいいか

**実装の難しさ**: 低〜中。物理は円同士の衝突・合体のみ。見た目の屈折（背景を水滴内で反転表示）はMetalシェーダか画像の反転で簡易再現可能。

**軽い競合確認の結果**
- 近い物: Strange Rain（雨の窓。古く現行iOSで未確認）、Drops Merge 3D（パズルゲーム、世界観が別）
- 水滴の合体を傾きで操作する「窓の雨」玩具は検索で見つからなかった。ただし雨の壁紙・環境音アプリは多く、「雨」というキーワード自体は競合が多い

**収益化の想像**: 景色パック（夜の街・車窓・朝の森）買い切り、雨量や水滴の大きさのカスタム。候補Aと統合する選択肢もある（Aの水滴部分を拡張）。

### 候補C: 砂鉄の生き物（Ferro）

**どんな体験か**
真っ黒な液体金属のような表面。指を置くとその下から黒いトゲの塊がぞわっと立ち上がり、指と一緒に動く。指を離すとゆっくりとろけて平らに戻る。傾けると表面がうねり、2本指で大きなトゲ群を作れる。

**最初の30秒の気持ちよさ**
- 触れた瞬間に黒いトゲがぞわぞわ生える意外性
- 指を動かすとトゲが追いかけるようについてくる生き物感
- 指を離したときにとろけて戻る静かな余韻
- 触覚は、トゲが立つ瞬間の小さなトントン

**なぜ一人で続けたくなるか**
- 磁性流体は見ていて飽きない素材として知られており、手触りとビジュアルが一致する
- 色や光沢を変えてスクショ・動画で共有しやすい（映える）

**最小プロトタイプ案（3〜4日）**
- 2Dの高さマップ（ヒートマップ）を指の位置から盛り上げ、ライティングで金属の光沢を付ける簡易Metalシェーダ
- まず固定数のトゲ（点群）が指に引かれる動きだけ作り、光沢は後
- 判定基準: 触った最初の数秒で笑顔になれるか

**実装の難しさ**: 中〜高。見た目の品質がすべてなので、Metalシェーダの調整が重い。ios-engineerにとって最も難度が高い案。

**軽い競合確認の結果**: 磁場シミュレーター系（Magnetica等、Androidで確認）はあるが、「液体金属のトゲを指で遊ぶ」玩具型アプリは今回の検索で見つからなかった。ただし網羅的な確認ではない。3本目の「ひとり砂の庭」とは触る対象が異なる（砂の軌跡 vs 立ち上がる流体）が、「光と影の質感」を売りにする点は共通するため世界観が近いと感じられる可能性がある。

**収益化の想像**: 素材パック（水銀、オイル、溶岩など）、色テーマ、壁紙書き出し。

---

### 候補D: シャボン玉ふぅー（Fuu Bubbles）

**どんな体験か**
画面に息を吹くとシャボン玉が膨らんで飛び出し、虹色の膜をまといながらゆっくり漂う。傾けると流れ、指で触れると弾けて小さな飛沫と音と触覚が出る。長く息を吐くほど大きな玉ができる。

**最初の30秒の気持ちよさ**
- 吹いた息の強さと長さで玉の大きさが決まる
- 虹色の膜が揺らぐ表現
- 割れた瞬間の「ぱちん」という小さな触覚と音

**なぜ一人で続けたくなるか**
- 息を吐く行為そのものが気持ちを落ち着ける。呼吸のリズムを整える用途にも結び付けやすい（健康効果の断言は避ける）
- 1個ずつ丁寧に膨らませる遊びと、一気に吹いて大量に出す遊びを選べる

**最小プロトタイプ案（2日）**
- 息検知で円を生成し、息の強さで半径を決め、CoreMotionで流す。虹色は角度グラデーションの円でまず代用
- 判定基準: 息を吹いて大きな玉を作るのが気持ちいいか

**実装の難しさ**: 低。候補Aと同じ息検知を使う。

**軽い競合確認の結果**: AR Bubble、Bubbler AR（ARKit前提で空間にシャボン玉を飛ばす）が存在する。2Dで虹色の質感に特化し、触覚を重視する差別化は可能だが、独自性は他の3案より弱い。「バブルラップ」系の混雑したカテゴリに入り込むリスクもある。

**収益化の想像**: 玉の色・膜の質感パック、泡の背景（夕焼け、星空）。

## (d) おすすめ: 候補A「くもり窓」

理由:
1. 息で画面が反応する体験は、他のどのアプリにもない身体性で、初めて触った瞬間に驚きがある（かおゲーに欠けていた「触って即気持ちいい」が最も強い）
2. 2009年に実際に大ヒットした実績（iSteam 初月200万DL）があるが、現行品が見当たらない空白がある。需要の証明と競合の少なさが両立している
3. 背面カメラの景色を窓の外にする案で、毎回違う絵が生まれる。写真として残せるので、映え・共有・景色パック販売につながる
4. 実装は低〜中で、マイク・カメラ・CoreMotion・Canvasのみ。無料アカウント(Sideloadly)でも動く
5. 数日の最小プロトタイプで感触を確かめられるため、「企画は良いが触るとつまらない」リスクを早期に潰せる

プロトタイプでNGなら、Bの雨粒（物理がほぼ同じ）か、Dのシャボン玉（息検知を流用）へ切り替えが可能。

注意点・リスク:
- 息検知は環境によって誤検知する。プロトタイプで必ず実機確認し、長押しで曇らせる代替入力を残す
- カメラ映像を使う場合、カメラ許可と、他人の写り込みに関するプライバシー説明が必要（画像は端末内のみで保存・送信しない）
- 「単一の遊びで飽きる」リスクがある。景色の入れ替えと「書いた字が曇りで浮かぶ」遊びで広げる
- aso-marketerとの突き合わせはオーケストレーター仲介で後続（検索されやすさは「曇り」「窓」「ASMR」「リラックス」系だが未検証）

- HapticMaze / AetherMaze / Hourglass（傾き玩具の周辺競合）

- AR Bubble / Bubbler AR（シャボン玉）
- Candle Simulation / Virtual Lighter（息で操作するろうそく）
