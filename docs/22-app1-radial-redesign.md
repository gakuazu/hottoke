# カレイド日記 大改修: 「1日の輪」（時刻×活動量×活動種別）への転換

作成日: 2026-09-19
決定者: オーナー

## 背景

現状の「今日の模様」は9種類の数学模様を万華鏡の対称性で描いており、見た目は華やかだが「その日どう過ごしたか」と模様の対応が直感的に読み取れない。オーナーから「1日の活動と模様を直感的に紐付けて振り返れるようにしたい」との要望があり、模様の意味づけを根本から変える。

## 新しい模様の読み方（オーナー指示）

- **周方向（角度）= 24時間の時間の流れ**（時計のように1周で1日）
- **半径方向（中心からの距離）= どれくらい活動したか**
- **模様の形 = どういう活動か**（歩行・走行・車移動・自転車・静止）

## 進め方の決定

- まず**静止画（画像）**を作る。動画化は後回し（既存の動画機能は残すが、今回は触らない）。
- 半径の指標: **1時間ごとの歩数**（歩数計は1時間単位で取得し直せる）。歩数が出ない車移動・自転車は活動種別の継続時間で補う。
- 既存の9種類の数学模様: **活動の種類ごとの「形」に割り当てて再利用**する。
- 万華鏡の対称性（鏡写し・回転コピー）: **やめる**。角度が時刻を表すため、コピーすると読み取れなくなる。1日に1つだけの形になる。

## 技術メモ

- 活動区間（`ActivitySegment`）は既に開始・終了時刻を持つので、時刻×活動種別は現データで足りる。
- 半径用に「1時間ごとの歩数」（24回の歩数計クエリ）を`ActivityDataService`に追加する必要がある。端末が保持する履歴は直近約7日分まで。
- ビルドはGitHub Actionsのみ（ローカルXcode不可）。

## 追加決定（2026-09-19、オーナー）

- 角度は常に「0〜24時 = 0〜360度」で固定する。今日の途中でも、現在時刻までを360度に引き伸ばさない。
- 今日の画像は「現在時刻までの分」だけを描き、未来の範囲は空白にする（現在時刻の位置に控えめな目印）。過去日は24時間すべて描く。
- 今日の画像は都度更新できる。画面を開いたとき／アプリに戻ったとき／更新ボタンで、最新の活動データを取り直して再描画する。
- 周方向（時刻方向）の模様の切り替えは不連続にせず、連続性を持たせる。活動種別の境目での形・色・半径のクロスフェード、半径の階段状でない滑らかな補間、時間帯の境目での色の連続変化を行う（2026-09-19、オーナー）。
