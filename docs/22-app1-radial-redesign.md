# カレイド日記 大改修: 「1日の輪」（時刻×活動量×活動種別）への転換

作成日: 2026-09-19
決定者: オーナー

## 背景

現状の「今日の模様」は9種類の数学模様を万華鏡の対称性で描いており、見た目は華やかだが「その日どう過ごしたか」と模様の対応が直感的に読み取れない。オーナーから「1日の活動と模様を直感的に紐付けて振り返れるようにしたい」との要望があり、模様の意味づけを根本から変える。

## 新しい模様の読み方（オーナー指示）

- **周方向（角度）= 24時間の時間の流れ**（時計のように1周で1日）
- **半径方向（中心からの距離）= どれくらい活動したか**
- **模様の形 = どういう活動か**（歩行・走行・車移動・自転車・静止）

## 進め方の決定

- まず**静止画（画像）**を作る。動画化は後回し（既存の動画機能は残すが、今回は触らない）。
- 半径の指標: **1時間ごとの歩数**（歩数計は1時間単位で取得し直せる）。歩数が出ない車移動・自転車は活動種別の継続時間で補う。
- 既存の9種類の数学模様: **活動の種類ごとの「形」に割り当てて再利用**する。
- 万華鏡の対称性（鏡写し・回転コピー）: **やめる**。角度が時刻を表すため、コピーすると読み取れなくなる。1日に1つだけの形になる。

## 技術メモ

- 活動区間（`ActivitySegment`）は既に開始・終了時刻を持つので、時刻×活動種別は現データで足りる。
- 半径用に「1時間ごとの歩数」（24回の歩数計クエリ）を`ActivityDataService`に追加する必要がある。端末が保持する履歴は直近約7日分まで。
- ビルドはGitHub Actionsのみ（ローカルXcode不可）。

## 追加決定（2026-09-19、オーナー）

- 角度は常に「0〜24時 = 0〜360度」で固定する。今日の途中でも、現在時刻までを360度に引き伸ばさない。
- 今日の画像は「現在時刻までの分」だけを描き、未来の範囲は空白にする（現在時刻の位置に控えめな目印）。過去日は24時間すべて描く。
- 今日の画像は都度更新できる。画面を開いたとき／アプリに戻ったとき／更新ボタンで、最新の活動データを取り直して再描画する。
- 周方向（時刻方向）の模様の切り替えは不連続にせず、連続性を持たせる。活動種別の境目での形・色・半径のクロスフェード、半径の階段状でない滑らかな補間、時間帯の境目での色の連続変化を行う（2026-09-19、オーナー）。

## 表現方式の変更: 「Cycle of Many」型の点描リング（2026-09-19、オーナー）

参考: https://flowingdata.com/2021/08/25/cycle-of-many/ （Nathan Yau、American Time Use Surveyの24時間スナップショット。1周が24時間、活動ごとに固定の輪があり、点の多さがその時刻にその活動をしていた割合を表す）

- 数学模様（9スタイル）は「1日の輪」では使わない。点描に置き換える。
- **周方向** = 24時間（0時が真上、時計回り）。これまでの決定（今日は現在時刻まで／都度更新／連続性）は維持。
- **半径** = 活動の種類ごとの輪（リング）。半径は「種類」を表し、「量」は点の密度で表す（従来の「半径=歩数」から変更）。
- **点の数** = その時間帯にその状態だった頻度（分数、歩行・走行は歩数も反映）。

## 「今日の模様」自体を点描リングに置き換え、数学模様は一旦廃止（2026-09-19、オーナー）

- 「今日の模様」タブの中身を点描リングにする（別タブ「1日の輪」は統合）。
- 数学模様（9スタイル）と、それに依存する手動モード（振る・傾ける万華鏡）はUIから外す。「一旦」廃止なのでコードは削除せず残し、復活できるようにする。
- 過去の模様アーカイブは、日付を選ぶとその日の点描リング（静止画）を表示する形に差し替える。

## 実装メモ: 点描リングの仕様（2026-09-19）

- 輪の順序（外側→内側）と半径（最大半径=1）: 静止 0.80〜1.00（最も広い）/ 車移動 0.66〜0.78 / 自転車 0.52〜0.64 / 歩行 0.32〜0.50 / 走行 0.18〜0.30。中心（0.18未満）は空ける。半径は歩数に比例させない。
- 色（活動ごとに固定）: 静止=青 #6f86ff / 車移動=紫 #c08cff / 自転車=琥珀 #ffb43e / 歩行=ミント #4fe8b0 / 走行=ピンク赤 #ff5f8a。
- 点の数: 1日を5分ごとのスライス（288個）に分け、活動ごとに「そのスライスのうちその活動だった割合」を出し、輪の面積から決めた点の容量を掛ける。歩行・走行は歩数が少ないほど薄く（下限0.6倍）。活動区間の検出漏れで歩数だけある時間は歩行として補う。
- 連続性: 密度は前後20分（4スライス）を三角形の重みで平均する。過去日は0時と24時をつないで平均する。
- 点の配置: 日付を種にした乱数で決めるので、同じ日は毎回同じ絵になる。

## 追加決定: 「今日」タブとアーカイブを点描リングに統合（2026-09-19、オーナー）

- 「今日の模様」（動画）を廃止し、「今日」タブ = 点描リングの静止画にする（更新: 開いたとき・前面復帰・更新ボタン。保存は画像）。別タブ「1日の輪」は統合して重複させない。
- 数学模様（9スタイル）と手動モード（振る・傾ける万華鏡）はUIから外す。コード（KaleidoscopeRenderer、PatternStyle、動画書き出し、TodayView、ManualModeView、ArchivePatternStore等）は削除せず残す（復活しやすくするため）。
- アーカイブは、日付を選ぶとその日の点描リング（24時間すべて）を表示する。端末の履歴は直近約7日分までなので、それ以前は「データなし」。動画キャッシュには依存しない。
- タブ構成の最終形: 今日 / アーカイブ / 設定。

## 半径の意味づけを「活動の強さの山」に変更（2026-09-19、オーナー選択：案A）

- 活動の種類ごとの輪（帯）に分ける方式は、絵がスカスカになったため廃止。
- 半径 = その時刻の活動の強さ。中心の小さな空洞から、強さに応じた半径までを点で埋める。外側の輪郭が1日の起伏になる。
- 色 = 活動の種類（境目は連続的に混ぜる）。点の詰まり = その状態だった頻度（分数、歩行・走行は歩数も加味）。
- 周方向（0〜24時、現在時刻まで、都度更新、連続性）は維持。
- 検討して採らなかった案: B 積み上げの渦巻き／C 静かさ→激しさの連続軸／D 1週間の年輪（将来の週間ビュー候補）／E 積み上げ帯。

## 実装メモ: 「活動の強さの山」の仕様（2026-09-19）

- 半径（最大半径=1）: 中心の空洞 0.14。外側の半径 = 0.27 + 0.73 × (1 − exp(−強さ/70))。強さは1分あたり歩数換算（歩/分）。静止は強さ0で最小半径0.27（空洞のすぐ外に薄く見える）。
- 強さ: 5分ごとのスライスで、活動の割合 × 歩/分 の合計。歩行・走行 = その時間の歩数 ÷ 歩行・走行していた分数（上限200、歩数0なら仮に60）、自転車 = 90、車移動 = 30、静止 = 0。活動区間に歩行がなくても、その時間に300歩以上あれば歩行として扱う（検出漏れ対策）。
- 点の数 = 密度 × 面積。密度 = 何かをしていた割合 × 歩数による濃さ（歩行・走行は0.6〜1倍）。空洞から外側の半径までを面積が均等になるよう埋める。
- 色: 点ごとに、そのスライスの活動の割合（時間方向に前後20分で平均済み）で確率的に種類を選ぶ。静止=青 #5b79ff、車移動=紫 #d27cff、自転車=琥珀 #ffb43e、歩行=ミント #4fe8b0、走行=ピンク赤 #ff5f8a（静止と車移動を離すため、当初指定の青・紫の色味を少し調整）。
- 見た目: 中心付近は小さく暗く、外縁ほど大きく明るく白に近づく。外縁の外側に光の飛沫、内側に少数のボケ、輪郭に活動の色の細い光の線、背景に星屑・星雲のにじみ・ビネット。目盛りは弱・中・強の目安の点線の円（20/60/120歩/分）と1時間ごとの細い目盛り。
