# Phase 1→2 移行決定: 3本目のアプリ「ひとり砂の庭」

作成日: 2026-09-13
決定者: オーナー

## 決定事項

3本目に開発するアプリとして、`docs/16-app3-bold-ideas.md` 案4「傾けて描く、ひとり砂の庭（Tilt Sand Garden）」を選定する。

- CoreMotion（重力ベクトル、Apple標準・無料）でiPhoneを傾け、画面内の玉を転がして軌跡を「砂紋」として残す、一人用の創作・瞑想ツール。
- 玉は直接タップでは動かせず、傾きの物理シミュレーション（慣性・摩擦）を通じてのみ操作する間接操作が核。
- オーナーからの重要な方向性指示: **「かなりいいアートができるように、インスタ映えするように」**。単なる線の描画ではなく、実物の「Sisyphus Table」（磁石で玉を転がして砂に溝を描くキネティックアート作品）のような、**光と影で砂の溝の陰影を表現する**ビジュアル品質を目指す。これを仕様・デザインの最重要要件とする。

## 注意点（申し送り）

- 操作方式そのものに近い競合（「Zen Garden」、穴に玉を導くパズルゲーム）が存在する。差別化として「ゴールのない自由創作」という方向性を仕様に明確に打ち出す。
- 1本目「カレイド日記」（万華鏡の対称模様）と世界観が近い部分があるため、「対称・幾何学」対「有機的な1本の曲線」という表現の違いを意識する。

## 進め方

- 1本目「カレイド日記」（Phase 3実装中）・2本目「かおゲー」（保留中、`docs/15-app2-shelved-decision.md`）とは独立に進める。
- Phase 2（仕様・デザイン）をこれから開始する。product-researcherが仕様書を作成し、オーナー承認後にux-designerが画面構成・ワイヤーフレームを作成する。
