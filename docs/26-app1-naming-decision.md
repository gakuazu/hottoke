# アプリ名称の決定（現称: カレイド日記 → トキノワ）

決定日: 2026-09-26
決定者: オーナー
関連: `docs/24-app1-naming-ideas.md`（product-researcherの自由発想・候補案）／`docs/25-app1-naming-aso-review.md`（aso-marketerのASO観点レビュー）

## 決定事項

アプリの表示名を **「カレイド日記」→「トキノワ」** に変更する。

## 経緯（かんたんに）

- 現在名「カレイド日記」は、初期の鏡写し・回転コピーによる「万華鏡」表現に由来していたが、その後アートの表現を作り替え、現在の標準表現は「花のコロナ」ほか7種類（いずれも鏡写し対称ではなく、24時間の時間のリングから活動を描く表現）になり、名前と見た目が合わなくなっていた。
- product-researcherが自由発想で約35案を出し、軽い競合確認を経て5案に、aso-marketerが独立にASO観点で分析（検索されやすさ・既存アプリとの重複リスク）。
- オーケストレーターが両者の結果を統合し、さらにオーナーの希望（4文字程度・親しみやすさ・意味があること→後に「リングを入れるなら4文字でなくてよい」に変更、万歩計のニュアンスも検討）に沿って追加候補を出す複数ラウンドを実施。
- 最終的に、競合確認済みの3候補（一日花・ヒカリノワ・トキノワ）の中から、オーナーが **「トキノワ」（時の輪）** を選択。

## 「トキノワ」を選んだ理由（参考）

- 4文字で発音・入力ともに軽い
- 「時の輪」＝24時間を1つの輪として描くという、アプリの核心の仕組みそのものを表している
- product-researcherの軽い競合確認で、同名アプリは見当たらなかった（`docs/24-app1-naming-ideas.md`の競合表を参照。ただし一般公開前に、より広い最終確認をおすすめする）
- 「コロナ」「カレイド」「ライフログ」「サイクル」など、aso-marketerが避けるべきとした語を含まない

## 次のアクション

1. アプリ内の表示名（`Info.plist`のCFBundleDisplayNameほか、UI上に「カレイド日記」と出ている箇所があれば）を「トキノワ」に変更する（ios-engineerに依頼）。
2. アプリアイコンは、この名称・世界観（時の輪＝花のコロナのリング状の光）に合わせて次に検討する。
3. 一般公開（App Store掲載）が具体化する段階で、念のためもう一段の商標・重複確認を行う。
