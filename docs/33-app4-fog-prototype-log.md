# 33. 4本目「くもり窓」感触確認プロトタイプ 記録

目的: 実機で30秒触って「また撫でたい」と感じるかの検証（本格実装ではない）。元案は docs/31 候補A。

## 置き場所・ビルド
- `fog/`（XcodeGenの `project.yml`。xcodeprojはコミットせずCIが毎回生成）。既存の `app/` と `ios-build.yml` は未変更（そちらは `app/**` の変更時のみ動くため、fog/ の変更では走らない）。
- ワークフロー `.github/workflows/fog-build.yml`（`fog/**` 変更時のみ）。シミュレータービルド、ユニットテスト、署名なしIPA作成。
- Bundle ID `com.gakuazu.hottoke.fog`、表示名「くもり窓」、iOS17+、iPhone縦固定。Artifact名 `Fog-unsigned-ipa`。
- 初回Actions実行 40041643822 で全ステップ成功（テスト含む）。

## 作ったもの
- 背景: コードで描いた夕暮れの街（画像同梱なし）。左下ボタンで写真ライブラリから1枚選択可（PhotosPicker、権限不要）。
- 曇り: 背景をぼかした画像＋白42%を、低解像度(横150セル)の濃度マスクで重ねる。指でなぞるとマスクが削れ、くっきり背景が出る。毎フレーム更新するのは小さなマスクと水滴の形だけで軽い想定。
- 再曇り: 毎秒一定量ずつ濃度が戻る（初期0.08/秒＝約12秒で元に戻る）。
- 息検知: AVAudioEngineで音量(RMS)と約500Hz以下の割合を算出。ノイズ床に緩やかに追従して騒音を差し引き、0.1秒以上続いたときだけ息と判定。音は保存・送信しない。
- 代替: 2本指で0.35秒長押しの間、全体が曇る。設定画面に「いま曇らせる」ボタンも。
- 水滴: 拭いている縁にときどき発生、少し膨らんでから傾き（CoreMotion）方向へ垂れる。ときどき止まり、通った跡は部分的に拭われる。スマホが水平だと動かない。
- 触覚: 約10pt動くごとに弱いインパクト。録音中でも鳴る設定済み。
- 隠し設定: 3本指タップ。息の感度・曇る速さ・再曇りの速さ・水滴の頻度・拭く太さ・触覚ON/OFF、息メーター（音量と低音割合の実測表示）。値は端末に保存。

## 判断
- Canvas/Metalではなく、CALayer＋低解像度マスクにした（GPU合成で軽く、実装が単純）。
- 息の判定式は簡易。実機の実測を見て閾値を詰める前提（メーター表示を用意）。

## 既知の制限・未検証
- 実機未確認。息検知の精度、触覚の心地よさ、60fps維持は未検証。
- 曇りの質感は「ぼかし＋白」のみ（屈折・結露の粒感なし）。水滴は単純な楕円。
- 息検知は低音比率が閾値(0.3)を超える雑音を息とみなすため、扇風機・車内などでは誤作動の可能性。
- 音楽再生中は mixWithOthers で共存させているが、他アプリの音に影響が出ないかは未確認。
- 景色の写真保存・カメラ映像は未実装（今回の対象外）。
- 署名なしIPAのためSideloadlyで7日ごとに再インストールが必要。
