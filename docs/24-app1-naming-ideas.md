# アプリ名称変更案（現称: カレイド日記）

作成日: 2026-09-26
担当: product-researcher
関連: `docs/23-radial-art-concepts.md`（表現の設計方針）／`docs/04-build-log.md`（実装の変遷）／`docs/00-setup-checklist.md`（配布方針）

このドキュメントは「良い名前とは何か」だけを軸にまとめたもの。検索されやすさ（ASO）の観点は別途aso-marketerがレビューする予定なので、ここではあえて深追いしていない。

## 0. まず整理したこと（なぜ名前を見直すのか）

「カレイド日記」という現在名は、初期の実装（鏡写し・回転コピーで模様を組み立てる、本物の万華鏡のような表現）に由来している。しかしその後、表現は「数学模様」を経て、現在の標準表現である**花のコロナ**（24時間の時間のリングから、その日の活動が花びらとして外側へ開く）に置き換わった。花のコロナをはじめ、選べる7種類の表現（コロナ／多重の花／週の年輪／オーロラ／渦巻き／点描の山）はどれも「鏡写しの対称模様」ではなく、**1日の記録を円形の絵にする**という共通点でまとまっている。

つまり今の「カレイド」という言葉は、もう実際の見た目を正しく説明していない。名称変更は、今の絵（時計の文字盤のような円、花・輪・光、日々積み重なる記録）に合った名前に直す機会だと考えて進めた。

## 2. 選別（8〜10案に絞る）

以下の観点で絞り込んだ。

- (a) 発音しやすい・覚えやすい・打ち込みやすいか
- (b) 「花」「輪」「光」「一日」など今の絵の世界観と合っているか
- (c) 子供っぽすぎない／安っぽすぎないか
- (d) 「カレイド」という響きを残すかどうか、両方のパターンを含める

主に外した理由（グループ単位で）:

- **コロナ日記／オーロラ日記**: 「コロナ」は新型コロナウイルスの連想が今も強く、アプリ内の表現名（機能名）とも紛らわしい。世界観に合っていても採用は避けたい。
- **環日記**: 「環」は普通「かん」と読み、「わ」と読ませるのは無理があって誤読されやすい。
- **リングダイアリー／サークルダイアリー／RingLog**: カタカナ英語で少し無機質。データの記録感が強く出すぎて、花や光の温かみが伝わりにくい。
- **光の花弁／光年輪**: 字面が難しく、パッと読めない（特に「ひかりねんりん」は長い）。
- **カレイド暦／万華日記**: カレイド系の中でも語感が硬く、選びにくい。
- 上記以外にも似た案が重複していたものは、より字面・読みが良い代表案だけ次の段階に残した。

## 3. 軽い競合・重複確認（ここで初めて競合を見た）

App Store・Web検索で、似た名前のアプリがないか確認した結果。

| 候補 | 確認結果 | 判定 |
|---|---|---|

| 一日花 | 同名アプリなし。「一日花」は朝顔・カンナ・ヘメロカリスなど「一日だけ咲いて萎れる花」を指す実在の園芸用語で、アプリ名としての使用例は見当たらなかった | 問題なし |
| ヒカリノワ（光の輪） | 同名アプリなし。日記アプリの検索でもヒットしない | 問題なし |
| 輪日記 | 同名アプリなし | 問題なし |
| ときのはな（時の花） | 同名アプリなし（無関係な花識別アプリ・花屋アプリはヒットするが同名ではない） | 問題なし |
| ヒビハナ（日々花） | 検索の限界はあるが、直接のヒットは見当たらない | 問題なし（採用前に再確認推奨） |
| トキノワ（時の輪） | 同名アプリなし | 問題なし |
| カレイドリング | 同名アプリなし。ただし「Kaleido」を冠したアプリがApp Storeに複数存在（Kaleido AR、Kaleido - A symmetry game、Kaleido-Art、Kaleido Web Browserなど）。「カレイド」接頭辞は競合が多く埋もれやすい | 要注意 |

## 4. 最終候補（3〜5案）

競合確認を踏まえ、次の5案に絞った。カレイドを残す案は1つ（カレイドリング）を代表として残している。

### 案1: 一日花（いちにちばな）

- **一言コンセプト**: 「一日だけ咲いて、その日限りで完成する花」という意味の言葉をそのままアプリ名に。今日の活動記録が今日だけの一枚の花として生まれ、また明日は新しい花が咲く、というアプリの仕組みそのものを表す
- **向いている理由**: 「1日1枚、その日だけの絵が確定する」という仕様と、意味が完全に一致している。実在の言葉なので変に子供っぽくならず、大人が使う日記アプリとしての品もある。「カレイド」を引きずらない完全な再出発になる
- **懸念点**: 「一日花」という言葉自体を知らない人には、パッと見て意味が伝わりにくい（サブタイトルでの補足が必要）。読み方（いちにちばな）に少し慣れが要る

### 案2: ヒカリノワ（光の輪）

- **一言コンセプト**: 「光の輪」＝コロナ・光暈（ハロー）のイメージを、パンデミック連想のある「コロナ」という単語を使わずに表現した名前
- **向いている理由**: 発音・入力ともに短くやさしい。今の表現（時間のリング、光のにじみ）と素直に合う。競合も見当たらず、ブランドとして独自の座席を取りやすい
- **懸念点**: 「花」の要素が名前に出ていないため、標準表現が「花のコロナ」であることは名前だけでは伝わらない（アイコン・説明文で補う前提）

### 案3: ハナドケイ（花時計）

- **一言コンセプト**: 「花の時計」＝文字盤のような円形に花が咲くイメージを、そのまま親しみやすい既存の言葉で表現
- **向いている理由**: 「花時計」自体は日本語として既にある言葉（花壇を時計の形に植えた庭園装飾）なので、説明なしでも温かく懐かしいイメージが伝わる。発音・記憶のしやすさは今回の候補の中で最も高い
- **懸念点**: 海外App Storeに「Floræ - Linnaeus' Flower Clock」という、時刻ごとに花が開く花時計アプリが既にあり、企画の着想が近い。名前は衝突しないが、説明文などで独自性（活動データから毎日違う絵になる点）を明確に打ち出す必要がある

### 案4: 輪日記（わにっき）

- **一言コンセプト**: 「輪」（時間のリング・積み重なる日々の輪）＋見慣れた「日記」の組み合わせ
- **向いている理由**: 既存の日記アプリの多くが「〇〇日記」という名付け方をしており、ジャンルとして素直に伝わる。字面がシンプルで安っぽさもない。競合も見当たらない
- **懸念点**: 5案の中では最も無難・地味な部類で、「花」「光」といった華やかさの記憶に残る度合いはやや弱い

### 案5: カレイドリング（カレイドを残す代表案）

- **一言コンセプト**: 現在名「カレイド」の響きを残しつつ、今の表現が「花のコロナ」＝リング状であることに合わせて「リング」を組み合わせた名前
- **向いている理由**: 家族内で既に「カレイド」の名前に馴染みがある場合、名称変更のギャップが小さい。カタカナ表記は視覚的に目立つ
- **懸念点**: 今の絵はもう鏡写し対称の万華鏡構造ではないため、「カレイド」という言葉と中身にズレが生じたままになる。加えてApp Storeには「Kaleido」を冠したアプリが複数あり、名前の独自性という点では他の4案より弱い

## 6. product-researcherとしての所感（参考）

順位をつけるなら「今の絵（花のコロナ）の意味に一番忠実で、かつ競合の心配がない」という点で **一日花** と **ヒカリノワ** を上位に置きたい。「ハナドケイ」は覚えやすさで一番強いが、Floræという先行の類似企画がある点だけ認識した上で選んでほしい。「カレイドリング」は名残を惜しむ場合の保険として残したが、今の絵の実態とは一番ズレがある。

最終判断はオーナーにお願いしたい。この案（複数選んでいただいても可）を、次にaso-marketerが検索されやすさの観点でレビューする想定。

## 7. 次のアクション

1. オーナーがこの中から名称（または追加候補）を選ぶ、または絞り込みをやり直す
2. 選ばれた案（複数可）を、aso-marketerがASO観点（キーワード・カテゴリでの発見されやすさ）でレビューする
3. 市場性（本ドキュメント）とASO観点の両方の結果をオーケストレーターが突き合わせ、矛盾があれば調整した上でオーナーに最終確認する
